## 即时试验场 - 无后顾之忧的探索体验

InstantWorldMirror 为 Minecraft 玩家提供了一个即时可用的沙盒试验场。使用次元镜像镜或者天堂之镜，你可以在任意位置创建周围区域的镜像副本（**默认不复制生物**），在其中自由探索、测试和实验，而**不必担心对原世界造成任何影**响。

### 核心应用场景

- **模组测试**：在镜像世界中测试新模组的功能和兼容性，避免破坏主存档
- **红石调试**：复制你的红石装置进行反复测试和调试，无需担心拆装成本
- **冒险探路**：进入危险区域前用**次元镜像镜**复制世界，在合适的地点使用镜子直接返回主世界从而**规避战斗**
- **建筑设计**：使用**天堂之镜**，以创造模式在镜像中预览建筑方案，可以配合创世神模组直接在主世界复刻
- **服务器活动**：为玩家提供安全的活动空间，活动结束后镜像自动清理

## 特性

### 维度镜

维度镜是开启镜像世界的钥匙：

- 右键点击任意固体方块创建入口传送门
- **在镜世界中用镜子长按右键可以返回镜世界入口**
- 支持效率附魔，可降低使用冷却时间（每级减少 20%，满级为30s）
- 创意模式下无冷却限制
- 支持从主世界、下界、末地以及模组添加的自定义维度创建镜像

### 镜像世界机制

- 以传送门位置为中心复制指定半径内的地形（默认10区块，可配置1-32区块）
- 完整复制方块、方块实体、生物群系数据和结构信息
- 可选择性复制实体（生物、装饰物等）
- 自动同步源世界的天气和时间
- 默认禁止自然生物生成，可通过命令或配置开启

### 多人游戏支持

- 支持最多8个并行镜像维度，多名玩家可同时使用各自的镜像世界
- 同一传送门可供多名玩家进入同一镜像会话
- 完善的权限管理系统，服务器管理员可控制玩家的访问权限和物品携带规则
- 当所有玩家离开后，镜像世界自动进入清理流程

### 传送门系统

- 入口传送门在世界复制完成后开启，默认持续5分钟（可配置）
- 镜像世界内的返回传送门默认永久存在
- 支持在镜像世界中使用维度镜创建返回传送门
- 玩家死亡后自动返回源世界

### 性能优化

- 采用高度图扫描技术，跳过空气列，大幅减少无效复制
- 使用分段级别操作而非逐方块处理
- 顺序队列处理，避免服务器过载
- 智能清理机制，仅处理已修改的区块

## 安装

1. 安装 [NeoForge](https://neoforged.net/) 1.21+
2. 下载本模组 JAR 文件
3. 放入 `.minecraft/mods` 文件夹
4. 启动游戏

## 合成配方

```次元镜像镜
[玻璃]   [黑曜石] [玻璃]
[黑曜石] [末影珍珠] [黑曜石]
[玻璃]   [黑曜石] [玻璃]
```

```天堂之镜
[荧石]   [红石粉] [荧石]
[红石粉] [末影珍珠] [红石粉]
[荧石]   [红石粉] [荧石]
```

## 命令

所有命令以 `/iwm` 开头：

| 命令                                    | 描述                               | 权限         |
| --------------------------------------- | ---------------------------------- | ------------ |
| `/iwm return`                           | 强制返回源世界                     | 所有玩家     |
| `/iwm mob on/off/status`                | 控制镜像世界生物生成               | OP (Level 2) |
| `/iwm allow <玩家>`                     | 允许玩家使用镜像功能               | OP (Level 2) |
| `/iwm deny <玩家>`                      | 禁止玩家使用镜像功能               | OP (Level 2) |
| `/iwm itemtransfer <玩家> <true/false>` | 控制玩家物品携带权限               | OP (Level 2) |
| `/iwm status`                           | 查看维度池状态和玩家信息           | OP (Level 2) |
| `/iwm forceclear <维度>`                | 强制清理指定镜像维度               | OP (Level 3) |
| `/iwm purge`                            | 完全删除所有镜像世界存档（需重启） | OP (Level 3) |

## 配置

配置文件位于 `config/instantworldmirror-common.toml`

### 维度池设置

| 配置项            | 默认值 | 描述                                                |
| ----------------- | ------ | --------------------------------------------------- |
| dimensionPoolSize | 4      | 镜像维度池大小（1-8），决定可同时存在的镜像会话数量 |

### 世界复制设置

| 配置项               | 默认值 | 描述                                             |
| -------------------- | ------ | ------------------------------------------------ |
| copyChunkRadius      | 10     | 复制半径（区块），总复制区块数 = (半径\*2+1)^2   |
| copyChunksPerTick    | 2      | 每tick复制区块数，数值越大复制越快但可能造成延迟 |
| cleanupChunksPerTick | 4      | 每tick清理区块数                                 |
| edgeCleanupRadius    | 3      | BFS边缘清理扫描的额外半径                        |

### 传送门设置

| 配置项               | 默认值 | 描述                               |
| -------------------- | ------ | ---------------------------------- |
| entryPortalLifetime  | 300    | 入口传送门持续时间（秒），-1为永久 |
| returnPortalLifetime | -1     | 返回传送门持续时间（秒），-1为永久 |
| maxPortalLoadingTime | 600    | 传送门最大加载等待时间（秒）       |

### 物品与生物设置

| 配置项                 | 默认值 | 描述                                   |
| ---------------------- | ------ | -------------------------------------- |
| allowItemTransfer      | false  | 默认是否允许玩家携带物品返回           |
| mirrorCooldown         | 300    | 维度镜使用冷却（秒），效率附魔可降低   |
| copyEntities           | false  | 是否复制生物实体                       |
| copyDecorationEntities | true   | 是否复制装饰性实体（画、物品展示框等） |
| enableMobSpawning      | false  | 是否允许镜像世界自然生物生成           |

### 环境设置

| 配置项         | 默认值 | 描述                 |
| -------------- | ------ | -------------------- |
| copyBiomes     | true   | 是否复制生物群系数据 |
| copyStructures | true   | 是否复制结构数据     |
| copyHeightmaps | true   | 是否复制高度图数据   |

### 服务器限制

| 配置项                      | 默认值 | 描述                       |
| --------------------------- | ------ | -------------------------- |
| maxMirrorWorldsPerPlayer    | 1      | 每个玩家最大并发镜像会话数 |
| staleSessionCleanupInterval | 300    | 过期会话清理检查间隔（秒） |

### 客户端设置

客户端配置文件位于 `config/instantworldmirror-client.toml`

| 配置项          | 默认值 | 描述                      |
| --------------- | ------ | ------------------------- |
| showCooldownHud | false  | 在左上角显示冷却计时器HUD |

## 游戏玩法

1. 合成维度镜
2. 前往想要复制的区域
3. 右键点击固体方块创建入口传送门
4. 等待世界复制完成（传送门动画指示加载状态）
5. 进入传送门，开始在镜像世界中探索和实验，**在镜世界中用镜子长按右键可以返回镜世界入口**
6. 使用维度镜创建返回传送门，或使用 `/iwm return` 命令返回
7. 离开后镜像世界会自动清理，为下次使用做准备

## 注意事项

- 默认情况下，从镜像世界返回时不会保留在镜像世界中获取的物品
- 镜像世界中无法建造下界传送门或末地传送门
- 每次创建新的镜像会话都会重新复制世界
- 镜像世界的修改不会影响源世界
- 服务器管理员可以完全控制玩家的访问权限
