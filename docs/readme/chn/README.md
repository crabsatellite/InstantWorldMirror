## 这个模组做什么

InstantWorldMirror 可以从你站立的位置创建临时或永久的镜世界。你可以探索、测试建筑、尝试战斗，或查看重新生成的地形，而不会改变原来的世界。

模组围绕三面镜子设计。它们都会让玩家进入一个独立世界，但复制内容、游戏模式、永久保存和生成内容刷新规则不同。

## 选择镜子

- **世界映照镜**：默认镜子，会创建当前位置周围区域的临时镜像副本。
- **天堂之镜**：创建临时镜世界，进入后切换为创造模式，适合测试。
- **初梦之镜**：使用当前世界种子重新生成原始地形，忽略原世界里的玩家改动。

普通测试用世界映照镜；想在创造模式里试东西用天堂之镜；想看这片区域最初生成出来是什么样，用初梦之镜。

## 一次会话怎么走

- 手持任意镜子右键实体方块，可以创建入口传送门。
- 复制或生成完成后，进入传送门即可进入镜世界。
- 在普通镜世界里，长按右键世界映照镜或初梦之镜，可以返回入口。
- 天堂之镜只能从原来的入口离开。
- 玩家在镜世界死亡时，会回到源世界并恢复保存的状态。
- 同一名玩家同一时间只能有一个活动镜世界会话。
- 其他玩家可以使用同一个入口传送门，但必须等创建者先进入；如果创建者离开临时会话，其他玩家也会被送回。
- 如果玩家断线或重登时仍有已保存的镜世界状态，模组会尽量恢复原来的位置、背包和状态。
- 临时镜世界会在玩家离开后自动清理。

## 世界规则

镜世界复制会在配置的区块半径内复制方块、方块实体、生物群系、结构、高度图和可选实体。

初梦之镜使用源世界当前种子和区块生成器，重新生成地形、结构、生物群系、洞穴、表面和特性。初梦之镜进入时保留玩家当前游戏模式，物品带回规则和世界映照镜一致。

默认关闭自然生物生成；已有生物和生成战利品可以通过配置或命令控制。天气、时间和维度视觉效果会从源维度同步。镜世界内会阻止下界传送门和末地传送门。

默认情况下，从镜世界返回时不会保留在镜世界获得的物品。模组不会主动清理现有的饰品或能力背包；只保存和恢复原版背包与末影箱。

## 天堂沙盒

使用天堂之镜进入时，模组会保存你的背包和状态，清空沙盒背包，切换为创造模式，并在离开时恢复保存状态。

天堂之镜会在沙盒内给玩家一面对应镜子，方便继续使用菜单和返回流程。

## 附魔与冷却

- 生存模式使用镜子有可配置冷却；效率附魔会同时减少普通使用冷却和复苏刷新冷却，每级减少 20%，最低 30 秒。
- 创造模式不受镜子使用冷却和复苏刷新冷却限制。
- 带有永久附魔的镜子可以把完成复制的临时镜世界保存为永久镜世界，前提是玩家是管理员或被授予权限。
- 临时会话必须是用带永久附魔的镜子创建的，重新进入永久镜世界时也必须手持同类型的永久附魔镜子。
- 复苏只能附魔到初梦之镜。当配置或 `/iwm mob off` 关闭自然生物生成时，带复苏的初梦之镜可以在冷却结束后刷新生成生物和未开启的生成战利品。
- 普通镜子使用冷却按玩家记录；复苏冷却记录在初梦之镜物品本身。物品栏进度条和物品提示会显示复苏冷却，`showCooldownHud` 可以显示普通使用冷却。
- 创造模式物品栏的 World Mirrors 分类包含三面镜子，以及永久和复苏两本附魔书。
- 在生存流程中，永久可以通过常规附魔和交易获得；复苏按稀有战利品设计。

## 永久镜世界

永久镜世界使用独立于临时镜世界的维度池。永久池共有 8 个服务器全局槽位。

已完成的临时镜世界只有在创建时使用了永久附魔镜子，才能保存为永久镜世界；保存后会保留镜子类型。进入已保存的永久镜世界时，也需要手持同类型的永久附魔镜子。

Shift 右键打开居中的镜子菜单，可以保存、进入、离开、重命名或删除永久镜世界；Esc 或右上角 X 可以关闭。永久镜世界选择器会在命令里自动补全，例如 `slot_1`，玩家不需要复制原始 UUID。

状态命令会同时显示临时镜槽和永久镜槽。修复命令会扫描中断造成的死数据，并跳过仍然有玩家使用的活数据。永久镜世界会一直保留，直到所有者或管理员删除。

中断的永久保存会在服务器启动时或通过 `/iwm repair` 修复；`/iwm purge` 只删除临时镜世界文件夹，不会删除永久镜世界记录。

## 管理与清理

- 复制时高度图扫描会跳过空空气列。
- 分段操作和顺序队列可以降低服务器负载。
- 清理会记录被修改过的区块，并扫描复制半径边缘外延伸出去的方块。
- 服务器关闭时会保存待清理状态，并清空临时镜世界会话记录。

## 安装

1. 安装 Minecraft 1.21.1 的 NeoForge。
2. 下载本模组 JAR 文件。
3. 放入 `.minecraft/mods` 文件夹。
4. 启动游戏。

## 合成配方

世界映照镜：玻璃、黑曜石和末影珍珠。

```
[玻璃]   [黑曜石]   [玻璃]
[黑曜石] [末影珍珠] [黑曜石]
[玻璃]   [黑曜石]   [玻璃]
```

天堂之镜：萤石、红石和末影珍珠。

```
[萤石]   [红石粉]   [萤石]
[红石粉] [末影珍珠] [红石粉]
[萤石]   [红石粉]   [萤石]
```

初梦之镜：橡树树苗、玻璃、橡木原木和末影珍珠。

```
[橡树树苗] [玻璃]     [橡树树苗]
[橡木原木] [末影珍珠] [橡木原木]
[橡树树苗] [玻璃]     [橡树树苗]
```

## 命令

所有命令都以 `/iwm` 开头。

| 命令 | 描述 | 权限 |
| --- | --- | --- |
| `/iwm return` | 从镜世界返回源世界 | 所有玩家 |
| `/iwm mob on/off/status` | 控制镜世界自然生物生成和生成战利品保留 | OP 等级 2 |
| `/iwm allow <player>` | 允许玩家使用镜世界 | OP 等级 2 |
| `/iwm deny <player>` | 禁止玩家使用镜世界 | OP 等级 2 |
| `/iwm itemtransfer <player> <true/false>` | 控制玩家是否能把物品带回 | OP 等级 2 |
| `/iwm status` | 显示临时和永久镜槽状态 | OP 等级 2 |
| `/iwm persistent menu` | 打开永久镜世界菜单 | 玩家 |
| `/iwm persistent save [name]` | 把当前临时镜世界保存为永久镜世界 | OP 等级 3 或被授权玩家 |
| `/iwm persistent enter <selector>` | 通过补全选择器进入永久镜世界 | 有访问权限的玩家 |
| `/iwm persistent leave` | 离开当前永久镜世界 | 玩家 |
| `/iwm persistent delete <selector>` | 通过补全选择器删除永久镜世界 | 所有者或 OP 等级 3 |
| `/iwm persistent rename <selector> <name>` | 通过补全选择器重命名永久镜世界 | 所有者或 OP 等级 3 |
| `/iwm persistent grant <player>` | 授予永久镜世界创建权限 | OP 等级 3 |
| `/iwm persistent revoke <player>` | 撤销永久镜世界创建权限 | OP 等级 3 |
| `/iwm repair` | 自动修复中断死数据，不清理活数据 | OP 等级 3 |
| `/iwm forceclear <dimension>` | 强制清理一个临时镜维度 | OP 等级 3 |
| `/iwm purge` | 删除临时镜世界存档文件夹，需要重启 | OP 等级 3 |

## 配置

配置文件：`config/instantworldmirror-common.toml`

### 维度池设置

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `dimensionPoolSize` | 4 | 临时镜维度池大小，范围 1-8 |

### 世界复制设置

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `copyChunkRadius` | 10 | 复制半径，单位为区块 |
| `copyChunksPerTick` | 2 | 每 tick 复制的区块数 |
| `cleanupChunksPerTick` | 4 | 每 tick 清理的区块数 |
| `edgeCleanupRadius` | 3 | 边缘清理扫描的额外半径 |

### 传送门设置

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `entryPortalLifetime` | 300 | 复制完成后入口传送门持续秒数 |
| `returnPortalLifetime` | -1 | 返回传送门持续秒数 |
| `maxPortalLoadingTime` | 600 | 传送门最大加载秒数 |

### 物品与生物设置

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `allowItemTransfer` | false | 默认是否允许玩家把镜世界物品带回 |
| `mirrorCooldown` | 300 | 镜子使用冷却秒数，会被效率附魔降低 |
| `copyEntities` | false | 是否复制生物实体 |
| `copyDecorationEntities` | true | 是否复制装饰实体 |
| `enableMobSpawning` | false | 是否允许镜世界自然生物生成 |

### 环境设置

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `copyBiomes` | true | 是否复制生物群系数据 |
| `copyStructures` | true | 是否复制结构数据 |
| `copyHeightmaps` | true | 是否复制高度图数据 |

### 服务器限制

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `maxMirrorWorldsPerPlayer` | 1 | 每名玩家最大并发镜世界会话数 |
| `staleSessionCleanupInterval` | 300 | 过期会话清理检查间隔秒数 |

### 客户端设置

客户端配置文件：`config/instantworldmirror-client.toml`

| 配置 | 默认值 | 描述 |
| --- | --- | --- |
| `showCooldownHud` | false | 显示冷却计时 HUD |
