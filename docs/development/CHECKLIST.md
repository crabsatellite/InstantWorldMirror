## 五、命令系统

### 5.1 基础命令

- [x] `/iwm return` - 强制返回源世界
- [x] `/iwm mob off` - 关闭镜面世界生物生成
- [x] `/iwm mob on` - 开启镜面世界生物生成
- [x] `/iwm mob status` - 查看生物生成状态

### 5.2 管理员命令

- [x] `/iwm allow [玩家]` - 允许玩家进入镜面世界
- [x] `/iwm deny [玩家]` - 禁止玩家进入镜面世界
- [x] `/iwm itemtransfer [玩家] [true/false]` - 控制物品带回权限
- [x] `/iwm status` - 查看维度池状态
- [x] `/iwm forceclear [维度]` - 强制清理指定维度
- [x] `/iwm purge` - 完全删除所有镜像世界存档
