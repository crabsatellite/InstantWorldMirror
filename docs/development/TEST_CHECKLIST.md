# InstantWorldMirror 测试清单

> **测试说明**：按顺序执行每个阶段的测试，每完成一项打勾

---

## 阶段 0：测试准备

### 环境搭建

- [ ] 安装 mod 到客户端和服务端
- [ ] 准备测试世界（包含各种方块、建筑）
- [ ] 给自己一个镜子道具：`/give @s instantworldmirror:dimension_mirror`
- [ ] 确认有 OP 权限（主测试账号需要 **OP 等级 4**）
- [ ] 准备一个 **OP 等级 2** 的测试账号（用于权限测试）
- [ ] 准备一个 **无 OP** 的测试账号（用于权限测试）

### 测试场地准备（在主世界搭建）

- [ ] 放置一个箱子，里面放几个物品
- [ ] 放置一个盔甲架，穿上装备
- [ ] 挂一幅画
- [ ] 放置半砖和楼梯
- [ ] 搭建简单红石电路（拉杆+红石灯）
- [ ] 放置告示牌并写字
- [ ] 放置旗帜（带图案）

---

## 阶段 1：单人基础流程（创造模式）

> 目标：验证核心功能正常工作

### 1.1 首次使用镜子

- [ ] 手持镜子右键放置
- [ ] 镜子出现旋转动画
- [ ] 旋转停止后，走进镜子
- [ ] 成功传送到镜像世界
- [ ] 检查 `/iwm status` 显示 1 个世界在使用中

### 1.2 验证世界复制

- [ ] 箱子存在且内容物正确
- [ ] 盔甲架存在且装备正确
- [ ] 画存在且位置正确
- [ ] 半砖、楼梯方向正确
- [ ] 红石电路可以正常工作（拉杆能点亮红石灯）
- [ ] 告示牌文字正确
- [ ] 旗帜图案正确

### 1.3 返回主世界

- [ ] 找到返回镜子（金色/橙色粒子）
- [ ] 走进返回镜子
- [ ] 成功返回主世界原位置
- [ ] `/iwm status` 显示世界开始清理或已可用

### 1.4 命令 /iwm return 测试

- [ ] 再次进入镜像世界
- [ ] 输入 `/iwm return`
- [ ] 成功返回主世界

### 2.3 创造模式充能

- [ ] 右键镜子，充能立即补满
- [ ] 可以马上放置使用

## 阶段 4：死亡与物品栏测试

### 4.1 物品栏保存恢复

- [ ] 确认身上有物品
- [ ] 进入镜像世界，物品栏被清空/保存
- [ ] 在镜像世界捡起一些物品
- [ ] 返回主世界，原物品栏恢复
- [ ] 镜像世界捡的物品消失（默认 itemtransfer=false）

### 4.2 物品转移权限

- [ ] `/iwm itemtransfer @s true`
- [ ] 进入镜像世界，捡起物品
- [ ] 返回主世界，捡的物品保留

### 4.3 镜像世界死亡

- [ ] 进入镜像世界
- [ ] `/kill @s` 自杀
- [ ] 重生在主世界（不是镜像世界）
- [ ] 原物品栏正确恢复
- [ ] `/iwm status` session 已清理

- [ ] 进入镜像世界，确认也是夜晚
- [ ] `/weather rain` 设置主世界下雨
- [ ] 确认镜像世界也在下雨

## 阶段 6：命令系统测试

### 6.1 状态命令

- [ ] `/iwm status` 显示可用世界数量
- [ ] 显示使用中世界数量
- [ ] 显示清理中世界数量

### 6.2 生物生成控制

- [ ] `/iwm mob off` - 确认镜像世界不生成怪物
- [ ] `/iwm mob on` - 确认镜像世界生成怪物
- [ ] `/iwm mob status` - 显示当前状态

### 6.3 权限管理

- [ ] `/iwm deny TestPlayer` - 禁止 TestPlayer 使用镜子
- [ ] TestPlayer 尝试放置镜子，失败
- [ ] `/iwm allow TestPlayer` - 允许 TestPlayer 使用镜子
- [ ] TestPlayer 可以正常使用镜子

### 6.4 强制清理

- [ ] 某人在镜像世界中
- [ ] `/iwm forceclear instantworldmirror:mirror_world_0`
- [ ] 该玩家被踢出到主世界出生点
- [ ] 世界被清理

## 阶段 10：权限测试

### 10.1 普通玩家权限

- [ ] 可以使用 `/iwm return`
- [ ] 不能使用 `/iwm status`
- [ ] 不能使用 `/iwm allow`
- [ ] 不能使用 `/iwm deny`
- [ ] 不能使用 `/iwm mob`
- [ ] 不能使用 `/iwm forceclear`

### 10.2 OP 等级 2

- [ ] 可以使用 `/iwm status`
- [ ] 可以使用 `/iwm allow`
- [ ] 可以使用 `/iwm deny`
- [ ] 可以使用 `/iwm mob`
- [ ] 不能使用 `/iwm forceclear`

### 10.3 OP 等级 3+

- [ ] 可以使用 `/iwm forceclear`
- [ ] 可以使用 `/iwm purge`
